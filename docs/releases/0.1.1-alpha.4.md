# Spare 0.1.1 Alpha 4 — Optional Jobs Preview

Spare `0.1.1-alpha.4` keeps one active job at a time while adding a signed
first-party catalog and saved configurations for any number of installed
jobs.

## Added

- Signed `.sp` catalog packages with SHA-256 and Ed25519 verification
- Native package review with publisher, version, compatibility, checksum, and
  permission details
- Clipboard for expiring text, links, and small files
- Downloads with a one-at-a-time HTTP/HTTPS queue, progress, pause, resume,
  retry, and safe destination handling
- Monitor with HTTP, ping, and TCP checks, response history, and deduplicated
  failure/recovery activity
- Trusted-device pairing with expiring HttpOnly sessions, revocation, origin
  checks, and rate limiting
- A static catalog for Clipboard, Downloads, Monitor, and the planned Archive,
  Media, DNS, Ad Blocker, and Cameras jobs
- CLI and local service operations to review, install, inspect, switch, and
  uninstall optional jobs

## Changed

- Site, Drop, and Hook remain bundled and visible by default
- Optional jobs appear in My Jobs only after their package is verified and
  installed
- Activating another job saves the current profile and rolls back if the new
  job cannot start
- Every job receives separate private state, while selected folders and
  downloaded content survive package removal
- `.sp` opening now leads with native installation review; safe inert
  inspection remains a secondary action

## Security boundary

Optional packages are first-party metadata and assets only. They cannot add
executable code. Spare enables only an exact matching implementation already
compiled into this release and revalidates the private package copy before
making it available.
